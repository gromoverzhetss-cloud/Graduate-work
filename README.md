Тестирование сайта SkyPro, раздел "Личные события"
"https://teachers.skyeng.ru/schedule"
Тестирование функционала “Личные события” в разделе “Расписание” на портале преподавателя. 
Возможность создавать личные события, редактировать, устанавливать дату и время, а так же отмечать нужные события цветом

UI чек-лист:
1. Создать событие на русском языке
2. Создание события с названием и описанием на английском языке
3. Уменьшить масштаб итерфейса
4. Убрать видимость личных событий
5. Удаление события

API чек-лист:
1. Создание личного события
2. Переименовать событие
3. Создание личного события продолжительностью в 23ч59мин
4. Создание личного события продолжительностью в 25мин01сек
5. Удаление личного события

Запуск тестов:
pytest --alluredir allure-result
Конвертация в отчёт:
allure serve allure-result
